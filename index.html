Setelah menyelesaikan LKPD ini, peserta didik mampu:

  • Memahami tipe data String dan Number.

  • Mengolah teks dengan properti dan metode String.

03 Materi Singkat

Aa

String

Tipe data untuk menyimpan teks atau kumpulan karakter.

let nama = "Andi";
console.log(nama);
123

Number

Tipe data untuk menyimpan angka, baik bilangan bulat maupun desimal.

let harga = 15000;
let jumlah = 2;
console.log(harga * jumlah);

Metode String yang sering digunakan

Metode Fungsi Contoh
.length Menghitung jumlah karakter "Halo".length → 4
.toUpperCase() Mengubah menjadi huruf besar "halo".toUpperCase()
.toLowerCase() Mengubah menjadi huruf kecil "HALO".toLowerCase()
.trim() Menghapus spasi di awal dan akhir " halo ".trim()
